# CET-4 科学词根与句法全能终端 (MorphoSyntax Pro)

> 基于认知神经科学（DFAM 2.5s 自适应流利度判定、工作记忆深度冲刷与四轨双阶梯复核闭环）的单页面大学英语四级（CET-4）深度记忆终端。

---

## 🌟 核心特性

- 🧠 **双阶梯流利度模型**：
  - **首碰初筛**：正字法词长与设备自适应门限（基准 2.5s）；
  - **秒答晋级复核**：独立 16~24 题衰减窗口，有机微穿插（垫 1~2 题），确权升盒；
  - **错题双阶梯加固**：首碰做错后 4~7 题初次纠偏，做对后 13~17 题二次深度复核，真正修复记忆突触。
- 📚 **全量 2257 核心考纲词库**：包含词根词缀形态学拆解、真题语境搭配、英美音标。
- ☁️ **三阶代理穿透云同步**：内置 GitHub Gist 增量存盘流水线，在开启 VPN / Clash Verge / Mihomo 等代理环境下自动穿透。
- ⚡ **纯原生无依赖**：Vanilla JavaScript 架构，零外部框架，毫秒级响应，支持离线运行。

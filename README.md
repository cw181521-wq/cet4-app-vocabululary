# CET-4 科学词根与句法全能终端 (MorphoSyntax Pro)
## 0916C 线性马达 Web 端触觉与声学反相制动优化版

### 一、 核心升级与技术实现规范
本版本严格落实《0916C 线性马达 Web 端触觉与声学反相制动技术规范》，针对移动端闪卡交互与振动质感完成系统级重构：

1. **0916C 物理特性建模与触觉脉冲设计**：
   - 适配 0916C X 轴线性马达谐振特性 ($f_0 \approx 165\text{ Hz}$, $T \approx 6.06\text{ ms}$, 半周期 $T/2 \approx 3.03\text{ ms}$)。
   - **卡位阻尼 (Detent)**: 85px 阈值单次 5ms 脉冲 ($T/2$ 能量注入，不拖泥带水)。
   - **确认脱扣 (Snap)**:
     - 缓速滑动 ($v \le 1.4\text{ px/ms}$): 9ms 脉冲 ($1.5T$ 稳定能量)。
     - 极速甩卡 ($v > 1.4\text{ px/ms}$): `[9, 18, 6]` 复合脉冲序列，消除拖尾余振。
   - **回弹缓冲 (Cushion)**: 未达阈值松手平滑复位触发 3ms 微脉冲，模拟微触感回弹。

2. **Web Audio 离散反相声学制动缓冲池 (Acoustic Brake Engine)**：
   - 14ms (48kHz 下 672 采样点) 离散波形实时合成：
     - **0–2ms 瞬态高频脉冲**: 2.8kHz 冲击，模拟指尖实体微动开关的刚性 Click 质感。
     - **2–9ms 缺失基频谐波合成**: 165Hz、330Hz、495Hz 谐波能量注入，利用人耳心理声学听觉补偿小尺寸手机扬声器低频不足。
     - **9–14ms $180^\circ$ 反相制动钳位**: 严格反相消除扬声器振膜余振，尾端平滑归零避免破音/爆音 (Pop/Click)。

3. **移动端触控手势状态机与迟滞滤波**：
   - **施密特迟滞区间 (Hysteresis)**: 85px 触发阈值，75px 释放重置区间，彻底杜绝手指抖动导致的振动连击。
   - **速度与时间戳滤波**: $\Delta t > 12\text{ ms}$ 稳态瞬时速度提取与低通平滑。
   - **决策判定**: 位移 $\ge 85\text{px}$ 或速度 $v > 0.65\text{ px/ms}$ 即可触发翻卡决策，响应敏捷流畅。

### 二、 部署与使用
解压后直接使用浏览器打开 `index.html`，或部署在静态服务器 (如 GitHub Pages、Cloudflare Pages、Vercel 等) 即可开启完整 PWA 离线运行体验。

### 三、 闪卡光线效果 2.0：电光靛蓝液态边缘辉光与仿生呼吸系统
针对闪卡待判定状态（翻开背面思考阶段）与判定流交互进行了系统级光学与动力学升级：

1. **多频阶梯漫反射与菲涅尔边缘折射场 (Fresnel Rim Lighting)**：
   - **接触折射核 (0~2px)**: 超高锐度高亮边缘 (`0 0 0 1px`)，呈现液态玻璃厚度。
   - **近场电光晕 (8~22px)**: 高饱和度核心电光靛蓝 (`#6366f1` / `#818cf8`)，模拟通电充能发光。
   - **远场环境漫溢 (20~48px)**: 深度弥散柔光场，增强悬浮层级感。
   - **多主题适配**: 
     - 浅色模式: 纯净沉静专注，无警告性压迫；
     - 暗夜模式: 霓虹通透，加入天青冷白 (`#a5b4fc`) 边缘微色散；
     - 羊皮纸模式: 温润古典墨水蓝 (`#4f46e5`)，漫反射柔和不脏色。

2. **仿生非对称呼吸节律 (Bio-Pulse Rhythm)**：
   - 弃用机械对称的正弦波与易引起文字边缘抖动的 `transform: scale`。
   - 采用 2.6s 不对称律动：**800ms 快速充能升压 (Inhale) + 1800ms 柔缓漫溢衰减 (Exhale)**，纯由合成层 `opacity` 驱动，杜绝重绘与重排。

3. **手势拖拽 CSS 变量无级连续插值 (Dynamic Gesture Bleed)**：
   - 摒弃离散 class 硬切断，改用 CSS 自定义属性 `--glow-dynamic-opacity` 动态线性插值 ($0\text{px} \sim 60\text{px}$ 连续淡出)。
   - 手势移动时电光靛蓝线性让渡给左滑珊瑚红 / 右滑翡翠绿，松手未达标回弹时无缝恢复满光照。

4. **安全与防御性编程加固**：
   - 速度与位移输入参数的非有限数 (`NaN` / `Infinity`) 防护与 `Math.max(0, ...)` 钳位。
   - 模态切换与生命周期清理时 `clearPendingGlow()` 强制收拢，保证专注模式、盲打模式等其它训练子系统的零副作用隔离。

### 四、 闪卡三极光场闭环补全（翡翠绿与珊瑚红全通道贯通）
针对卡片切换时缺失红/绿反馈光效的系统级修复：

1. **红绿光晕体系全量注入**：
   - 为 `.card-correct-feedback`（掌握通过）与 `.liquid-glow-right` 挂载完整的翡翠绿多频外漫射场 (`#10b981` / `#34d399`)；
   - 为 `.card-wrong-feedback`（生疏重背）与 `.liquid-glow-left` 挂载完整的珊瑚红多频外漫射场 (`#ef4444` / `#f87171`)；
   - 内部导光管 `::after` 对应激活翠绿与珊瑚红通电流光 (`opacity: 1 !important`)。

2. **全端输入通道时序与脱手光轨对齐**：
   - 键盘快捷键 (`J` 掌握 / `K` 生疏 / 空格回车 / 左右方向键) 与按钮点击时，同步注入对应方向与色彩的光晕体系；
   - 触控脱手抛离视口时，保持红/绿光轨拖尾，直至下一张新卡片进场；
   - 新卡进场后由 `cleanup()` 统一清空，重新进入无光等待态，实现「蓝 (思考) -> 绿/红 (决策迸发) -> 无光 (新卡进场) -> 蓝」标准认知闭环。

### 五、 边框纯色转色与层叠优先级终极加固
针对切换卡片或手势拖拽时“卡片内部变色但边框残留蓝色”的深度修复：

1. **高权重复合选择器（Cascade Override）**：
   - 为 `.card-correct-feedback` 与 `liquid-glow-right` 增加包含 `.stage-card.flashcard-pending-decision` 的复合选择器（权重提至 4 个类名），确保无论任何状态重叠，实体边框与 1.5px 扩散外环统一被强制设定为纯翡翠绿（`#10b981`）；
   - 为 `.card-wrong-feedback` 与 `liquid-glow-left` 增加高权重复合选择器，强制覆盖为纯珊瑚红（`#ef4444`）。

2. **待判定蓝边注入手势动态淡出**：
   - 待判定蓝边从静态 `0.72` 改造为 `calc(0.75 * var(--glow-dynamic-opacity, 1))`，位移增加时蓝边透明度线性淡出归零。

3. **手势拖拽临界状态互斥（JS 插桩）**：
   - 在 `touchmove` 中实施 $\pm 18\text{px}$ 阈值互斥：向右拖动超 18px 立即剥离 `flashcard-pending-decision`，边框瞬变翡翠绿；向左拖动超 18px 立即剥离，边框瞬变珊瑚红；拉回中位自动补回待判定蓝光，彻底杜绝蓝边残留。

### 六、 左右滑动色彩饱和度与晕染范围精细化收窄
针对左右滑动时的视觉光效进行舒适度调优：

1. **晕染范围减半紧凑收拢**：
   - 远场外漫射扩散半径从原先的 $48\text{px} \sim 56\text{px}$ 大幅收敛至 $24\text{px} \sim 28\text{px}$，水平偏移由 $\pm 16\text{px}$ 降至 $\pm 8\text{px}$，避免大面积光场侵蚀视口周边；
   - 内部导光管 `::after` 的内嵌模糊由 $24\text{px}$ 收窄至 $14\text{px} \sim 16\text{px}$，光线更加贴合卡片边缘内沿。

2. **色彩饱和度降噪与通透度提升**：
   - **右滑掌握**：弃用高饱和鲜绿，改用低饱和温润的鼠尾草绿 (`rgba(46, 160, 120, 0.72)`)，降低视觉刺眼度；
   - **左滑生疏**：弃用警告性鲜红，改用柔和内敛的砖红/玫瑰珊瑚红 (`rgba(220, 95, 88, 0.72)`)；
   - **边框与底色轻量化**：边框不透明度从 $0.95$ 降至 $0.72$，卡片内部微弱底色填充从 $0.88$ 降至 $0.78$，保持通透微晶玻璃质感。

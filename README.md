## 一、方案落地与核心优化点总结
1. **闪卡构词精解“内嵌流式折叠”与局部视口预算 (Inline Flow Accordion & Viewport Budgeting)：**
   - 彻底将构词精解降维重构为闪卡卡片内部背面的顺位子元素（`#flashcard-embedded-analysis`）。当用户翻开闪卡时，精解在卡片内部随背面平滑风琴展开（`grid-template-rows: 0fr -> 1fr` 贝塞尔曲线过渡）。
   - 移动端小屏视口下，为主舞台卡片设定最大可用视口预算（最高不超过视口的 75%），字数过长时卡片内部局部垂直平滑滚动，外部根页面永远保持绝对“零滚动”，彻底根治了移动端视口跳跃与页面被强行顶出视口的痛点。
   - 引入平滑焦点对齐（Scroll Alignment），在翻卡与切词时保证视觉焦点始终处于黄金分割区。

2. **多模式视图状态“严格生命周期沙箱” (View Sandboxing & Teardown/Mount Lifecycle)：**
   - 实现了所有模式严格标准化的生命周期契约（`enter(prevMode)` / `leave(nextMode)` / `render(word)`）。
   - 调度中枢重构为“先销毁、后挂载”流水线：离开旧模式时物理级卸载专属 DOM 并清空状态、熔断计时器沙箱与音频，进入新模式时纯净挂载。
   - 切换至智能闪卡时，四选一选项容器物理清空并隐藏（`innerHTML = ''`, `display: none`），四选一与闪卡之间高速横跳零污染、零残留。

3. **全功能完整性与生产级保证：**
